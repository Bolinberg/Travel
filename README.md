# 自驾行程规划 App（MVP）

家庭自驾旅游计划工具。第一期只服务一个目标：**统筹 12 月墨尔本 → 阿德莱德的家庭自驾**——每天怎么走、住哪里、要花多少钱、出发前还差什么。

## 功能

| 页面 | 内容 |
| --- | --- |
| 地图 | 全程/按天查看真实驾车路线（每天一种颜色）、过夜地编号、途经景点；点标记看风景照片和介绍；下方显示当天景点、住宿、餐饮 |
| 概览 | 天数、总里程、驾驶时长、预计总花费；预算进度（人均 / 每天）；未订住宿和清单进度提醒；路线一览 |
| 行程 | 逐日卡片：出发地/目的地、里程、车程、途经景点、当晚住宿（价格、已订、已付、确认号），一键打开 Google 地图导航；可增删、排序。展开可看：景点照片与介绍、住宿推荐（一键选定并填入价格）、餐饮推荐（标记想去），均附 Tripadvisor / Google 地图 / Booking 链接 |
| 费用 | 按类别汇总（油费自动按 里程×油耗×油价 计算、住宿取自行程、餐饮按每人每天标准）；其他开销可增删、标记已付 |
| 清单 | 出发前 / 行李 / 路上注意 分组勾选，可自定义 |
| 设置 | 出发日期、人数、预算、车辆油耗与油价、餐饮标准；导出/导入 JSON（和家人共享）、打印/存 PDF |

数据保存在浏览器本地（localStorage），不需要账号和服务器。

联网时 App 会在设备上调用以下免费服务（结果缓存）：OpenStreetMap 地图瓦片、OSRM 驾车路线、维基百科景点照片、Nominatim 地点坐标查询。离线时路线显示为虚线直连。

住宿和餐饮推荐整理自 2025–2026 年 Tripadvisor、Wanderlog、OpenTable 与各地官方旅游网站上仍在营业的商家；价格是 12 月旺季一家四口的估算，预订前请以官网为准。

## 默认行程（9 天 8 晚，约 1,975 km）

墨尔本 → 大洋路（Apollo Bay、十二门徒岩、Warrnambool）→ Mount Gambier → Robe → 库隆 → 阿德莱德（3 晚）→ Halls Gap（格兰扁）→ 墨尔本。

所有里程、车程、住宿价格均为**估算值**，请按实际导航和预订结果修改。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm test         # 费用计算单元测试
npm run build    # 打包成单个 dist/index.html，可直接打开或发到手机
```

推送到 `main` 后，`.github/workflows/pages.yml` 会部署到 GitHub Pages（需在仓库 Settings → Pages 里把 Source 设为 GitHub Actions）。
